# Machine Learning Predictive Modeling & Classification

An end-to-end repository featuring supervised machine learning pipelines for regression and binary classification—covering price prediction, customer churn analysis, and medical diagnostic classification.

---

## 📌 Project Overview

This repository explores data preprocessing, feature engineering, and model evaluation across three key business and healthcare domains:

- **Real Estate Price Prediction (`price_pridiction_project.ipynb`)**:
  - Implements regression modeling to forecast property prices based on continuous and categorical features (e.g., location, area, and amenities).
  - Covers data cleaning, outlier handling, feature scaling, and performance evaluation using regression metrics (RMSE, MAE, R²).

- **Customer Churn Prediction (`churn prediction.ipynb`)**:
  - Predicts customer attrition likelihood from behavioral and account signals.
  - Balances class distributions and evaluates classification performance using precision, recall, F1-score, and ROC-AUC.

- **Breast Cancer Diagnostic Classification (`logistic regression and classification on breast cancer dataset.ipynb`)**:
  - Implements Logistic Regression and binary classifiers to detect malignant vs. benign tumors on diagnostic data.
  - Examines decision boundaries, feature correlations, and confusion matrices for high-stakes medical decision support.
